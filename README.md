# 🔥 트렌드 허브

지금 뜨는 걸 보고, 누르면 바로 **𝕏 글감**이 복사되는 폰용 도구 모음.
복사된 글감은 Claude에 붙여넣으면 튼튼혈관연구소 X 글로 바뀝니다.

| 도구 | 하는 일 | 필요한 것 |
|---|---|---|
| 🫀 **트렌드 헌터** (`hunter/`) | 떡상 중인 건강 유튜브 영상을 카테고리별로 | 유튜브 API 키 (기기마다 한 번) |
| 📊 **트렌드 뷰어** (`viewer/`) | 실시간 검색어 · 구글 트렌드 · 유튜브 인기 | 없음 (자동 수집) |

## 자동 수집

`.github/workflows/collect.yml` 이 한국 시간 **07:17 · 12:17 · 18:17** 에
`collect.mjs` 를 돌려서 `viewer/data/` 에 저장합니다. PC를 켜둘 필요 없습니다.

- 지금 바로 돌리기: **Actions** 탭 → **트렌드 수집** → **Run workflow**
- 전부 실패하면 저장하지 않습니다 (빈 데이터로 덮어쓰지 않음)
- 같은 날 일부 소스만 실패하면 그 소스는 앞서 받은 걸 유지합니다
- 60일 지난 데이터는 자동 정리

## 헌터 API 키

키는 **코드에 들어 있지 않고**, 각 기기 브라우저에만 저장됩니다.
폰에서 처음 열면 키 입력 화면이 나오니 한 번 넣어주세요.
(공개 저장소라 키를 코드에 넣으면 누구나 볼 수 있습니다.)

## 파일 구조

```
trend-hub/
├── index.html          입구 (폰 홈 화면에 추가할 페이지)

│   ├── index.html      트렌드 뷰어

├── collect.mjs         수집기

```

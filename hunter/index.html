🫀 튼튼혈관 트렌드 헌터

지금 떡상 중인 건강 콘텐츠를 카테고리별로 조회하고, 바로 X 글감으로 뽑아주는 대시보드입니다. 처음 한 번만 유튜브 API 키를 넣으면 돼요 (무료).

  1. Google Cloud Console 접속 → 새 프로젝트 만들기
  2. 검색창에 YouTube Data API v3 검색 → 사용 설정
  3. 왼쪽 메뉴 사용자 인증 정보 → API 키 만들기
  4. 생성된 키를 복사해서 아래에 붙여넣기

· 키는 이 기기의 브라우저(localStorage)에만 저장돼요. 폰·PC 각각 한 번씩 넣어주시면 됩니다.
· 무료 할당량: 하루 10,000 유닛 (이 대시보드 기준 하루 수십 번 조회 가능)
· 조회 결과는 1시간 캐시되어 할당량을 아낍니다.
